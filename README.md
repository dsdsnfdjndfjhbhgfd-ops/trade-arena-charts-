# Трейд Арена — графики

Сайт со свечными графиками криптовалют в реальном времени.

- Свечи и объём, таймфреймы от 1 минуты до 1 недели
- Индикаторы: MA 20, EMA 50, полосы Боллинджера, RSI 14
- Список рынков с изменением за 24 часа и мини-графиками
- Лента сделок и соотношение покупок и продаж
- Данные из публичного API Binance (REST + WebSocket). Если Binance недоступен, сайт переходит в демо-режим со сгенерированными данными
- Ссылку на конкретный график можно отправить: `#ETHUSDT/15m`

Один файл `index.html`, без сборки. Графики: [Lightweight Charts](https://github.com/tradingview/lightweight-charts) от TradingView.

Не является инвестиционной рекомендацией.
